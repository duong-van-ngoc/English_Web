# Phase 00 - Nen tang truoc khi code

## Muc tieu

Nam duoc cach mot ung dung web hoat dong tu frontend den backend va database. Phase nay giup ban khong bi roi khi bat dau code Next.js, NestJS, PostgreSQL va Prisma.

## Kien thuc can hoc

- Git co ban: `init`, `add`, `commit`, `branch`, `push`, `pull`
- Node.js va npm/pnpm
- TypeScript co ban: type, interface, function, class, generic co ban
- REST API: request, response, method, status code
- Database quan he: table, row, primary key, foreign key
- Cach frontend goi backend qua HTTP

## Thuc hanh trong project

- Tao repo `english-toeic-web`
- Tao cau truc:

```txt
english-toeic-web/
├── frontend/
├── backend/
├── docker-compose.yml
└── README.md
```

- Cai Node.js LTS
- Cai Docker Desktop
- Cai PostgreSQL bang Docker Compose
- Tao project Next.js trong `frontend`
- Tao project NestJS trong `backend`
- Push code len GitHub
