# Lo trinh xay dung English TOEIC Web

Stack chinh:

```txt
Frontend: Next.js + TypeScript + Tailwind CSS
Backend: NestJS + TypeScript
Database: PostgreSQL
ORM: Prisma
Auth: JWT
Deploy: Vercel + Render/Railway/Fly.io + Supabase/Neon
```

Muc tieu cua bo phase nay la vua hoc vua lam. Moi phase tap trung vao mot nhom kien thuc, sau do ap dung truc tiep vao web hoc tieng Anh cho nguoi moi va luyen TOEIC.

## Thu tu phase

1. `phase-00-nen-tang` - Nen tang truoc khi code
2. `phase-01-nextjs-co-ban` - Next.js co ban
3. `phase-02-nestjs-co-ban` - NestJS co ban
4. `phase-03-postgresql-prisma` - PostgreSQL va Prisma
5. `phase-04-ket-noi-fe-be` - Ket noi frontend voi backend
6. `phase-05-auth` - Dang ky, dang nhap, phan quyen
7. `phase-06-admin-noi-dung` - Admin quan ly noi dung hoc
8. `phase-07-engine-luyen-toeic` - Engine luyen cau hoi TOEIC
9. `phase-08-tien-do-on-tap` - Tien do hoc va on tap
10. `phase-09-audio-file` - Audio va file cho Listening
11. `phase-10-testing-code-quality` - Testing va code quality
12. `phase-11-deploy` - Deploy san pham
13. `phase-12-mo-rong` - Mo rong sau MVP

## Cach hoc moi phase

```txt
Hoc khai niem -> code vi du nho -> ap dung vao project TOEIC -> ghi chu lai -> refactor
```

Khong nen hoc Next.js va NestJS tach roi qua lau. Moi kien thuc nen gan voi mot tinh nang that trong san pham.
